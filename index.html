DECISION — Is this QR authentic, event-eligible, active and unredeemed?

All checks occur on the backend. A successful verification and redemption is one indivisible transaction.

YES → ADMIT

Mark checked-in and show positive confirmation with guest and ticket details.

ALREADY USED → DENY

Show first redemption time and gate, log attempted reuse, offer supervisor review.

INVALID → DENY

Reject altered, revoked, unpaid, wrong-event or unrecognised credentials.

Flow 03 / Exception management

Network unavailable

Revocation / refund

Multiple gate devices

Concurrent requests resolve to exactly one winner

SECURITY / ROLE-BASED ACCESS

The right access for every role.

Access is scoped by organisation, event and assignment. Unassigned staff cannot scan tickets even if they know a valid ticket ID.

GUEST

Ticket holder

Discover and purchase tickets, view owned passes, access receipts and permitted transfers.

ORGANISER

Event owner

Create events, configure ticket types, design passes, issue and revoke tickets, access event reporting.

SCANNER

Gate operator

Scan assigned event tickets and view only the minimum guest details needed for entry verification.

SUPERVISOR

Gate supervisor

Manage authorised staff, review exceptions, access gate-specific logs and reconcile attendance.

PLATFORM ADMIN

System administrator

Manage platform security, tenants, policies and abuse investigations with audited elevated access.

SYSTEM

Ticket service

Sign and verify ticket credentials, enforce state transitions, process payment confirmation and audit redemptions.

Foundations

Type

Inter/system sans · strong display hierarchy · 13–16px UI body · explicit verification text.

Spacing

8px base rhythm · 12–24px card padding · 10–20px radii · touch targets ≥44px.

Interaction

Navigation states · input validation · skeletons · loading · success, warning, error and offline states.

Accessibility

Text/icon/colour state cues · logical focus order · readable contrast · reduced motion support.

Ticket credential

Signed payload + unique server record; never include sensitive personal data in plain QR content.

Development

Next.js + Expo React Native + Supabase RLS, transactional redemption function, verified webhook handling.

Static design system and interactive UX prototype only. Ticket scans, payment confirmation, account login and issuance are illustrative until connected to production services.
