# Provider refund verification and release gates
The admin refund desk verifies an existing full processed sandbox refund by numeric provider refund ID. It performs a GET against Paystack, matches the transaction ID, NGN amount, test environment and processed status, then atomically records the settlement and audit. No provider refund is initiated here. Partial refunds, chargebacks, live processing, externally initiated refunds without a verified payment transaction ID, and active/redeemed tickets remain supervised exceptions. Apply the additive unique provider refund index in isolated staging before release. Provider docs: https://paystack.com/docs/api/refund/ .
 
Final acceptance requires a real sandbox transaction and independently verified refund receipt, signed Android/iOS artifacts for the exact commit, four-role authenticated browser and device tests, Resend inbox delivery and private email verifier configuration, security approval and production rollback rehearsal. Do not infer 99% from CI or older APKs.
